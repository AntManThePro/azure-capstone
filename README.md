# Azure Capstone

Interactive 3D showcase of a handmade four-sided teal-and-copper pyramid jewelry cabinet.

Open each face to the inner compartment, then fold those in to reveal the frosted-glass shrine. Pick jewelry from the tray and place it on a glowing ring.

Photo textures of the real cabinet are in `public/cabinet/`.

See [AZURE-CAPSTONE.md](AZURE-CAPSTONE.md) and [docs/AZURE-CAPSTONE.md](docs/AZURE-CAPSTONE.md).

## Run

```bash
npm install
npm run dev
```

Node 22+. No accounts. Jewelry layout persists in the browser as `azure-capstone-v1`.
