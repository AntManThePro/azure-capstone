# Photo textures

The GitHub file API cannot upload the cabinet JPEGs without corrupting them, so they are not in this repo yet.

From the Azure Capstone zip, copy these into `public/cabinet/`:

- outer-face.jpg
- inner-pegs.jpg
- inner-coils.jpg
- inner-shelves.jpg
- inner-vials.jpg
- teal-paint.jpg
- mosaic.jpg
- wood.jpg

Optional share images: `public/og.jpg`, `public/x-banner.jpg`, and `docs/gallery/*.png`.

Then `npm install` and `npm run dev`.
